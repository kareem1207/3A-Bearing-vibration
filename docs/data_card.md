# Data card

## Real dataset (target): NASA IMS bearing dataset
| Item | Value |
|---|---|
| Source | NASA Prognostics Data Repository, "IMS Bearings" (Univ. of Cincinnati Center for Intelligent Maintenance Systems), widely mirrored on Kaggle |
| Rig | 4 Rexnord ZA-2115 bearings on one shaft, 2000 rpm, 6000 lbs radial load |
| Sampling | 20 kHz, 1 second snapshot (20480 samples) every 10 minutes |
| Tests | Test 1: 8 channels (2 per bearing); tests 2 and 3: 4 channels (1 per bearing) |
| Failures | Test 1: bearing 3 inner race, bearing 4 roller; test 2: bearing 1 outer race; test 3: bearing 3 outer race |
| Labels | **None published.** Fault onset must be assumed (`FAULT_ONSET_FRACTION` in `src/imsae/ims_io.py`, currently an assumed 0.75 of each test) |
| Status in this repo | **Not downloaded.** The environment used to build the project could not reach the dataset hosts |

## Data actually used for the reported results: simulated IMS style runs
Generated by `src/imsae/simulate.py` (seeded, deterministic).

| Item | Value |
|---|---|
| Runs | 8 run-to-failure runs x 4 bearings = 32 series (3 train runs, 2 validation runs, 3 test runs, split by run) |
| Length | 700 snapshots per run (about 4.9 days at 10 minute spacing) |
| Healthy signal | Gaussian noise + shaft harmonics (33.3 Hz), 6 percent daily amplitude cycle, benign transient bursts (about 1.7 per day) that mimic faults |
| Fault | Outer race defect from a random onset at 60 to 85 percent of the run: impulses at 236.4 Hz ringing a 3.5 kHz resonance, amplitude 0.25 sigma at onset growing 40x |
| Class balance | One faulty bearing out of four per run; about 15 to 40 percent of that bearing's readings are faulty, so roughly 5 to 10 percent of all readings |
| Features | 11 per bearing per snapshot (log RMS, kurtosis, crest factor, 8 log band powers) |
| Training data | Only the first 40 percent of every training series (assumed healthy). The last 20 percent of that prefix is held out for early stopping. No fault labels are used |
| Labels use | Validation runs: threshold selection. Test runs: final numbers. Never training |

## Limitations
* Simulated data reproduces the *structure* of the problem, not the real noise, load changes, sensor drift or degradation physics. All absolute numbers must be re-measured on real data.
* Fault onset and severity growth are simulator parameters chosen by the authors (a0 = 0.25 sigma, growth 40x); results depend on them (see the sensitivity run in the report).
* "Healthy for the first 40 percent" is an assumption about the commissioning period.
